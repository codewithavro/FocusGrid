# FocusGrid
Tagline: A sleek, modern desktop task manager built in Python.  Tech Stack: Python, CustomTkinter, Pillow, and local JSON storage.  Core Features:  Secure Authentication: User sign-up, login, and SHA-256 password hashing.  Account Recovery: Password reset via custom security questions.  Task Management: Add, view, and delete personal tasks inside a scrollable workspace.  Data Persistence: Automatically manages local user records, task lists, and theme settings (.json).  Modular Architecture: Clean separation of concerns across views, business logic, and theme managers
